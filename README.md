# 📒 Agenda de Contatos em Python

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação, funções, listas, dicionários e manipulação de dados.

A aplicação funciona pelo terminal e permite cadastrar, visualizar, editar, favoritar e remover contatos.

## 🚀 Funcionalidades

- Adicionar contatos
- Visualizar todos os contatos cadastrados
- Editar contatos
- Favoritar ou desfavoritar contatos
- Visualizar apenas contatos favoritos
- Apagar contatos
- Menu interativo pelo terminal

## 🛠️ Tecnologias utilizadas

- Python 3

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto foram utilizados conceitos como:

- Funções
- Listas
- Dicionários
- Estruturas condicionais
- Laços de repetição
- Entrada de dados com `input()`
- Manipulação de índices
- Métodos de listas como `append()` e `pop()`
